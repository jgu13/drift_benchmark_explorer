# Gorilla CLI v2 Migration Notice

Effective immediately, several command interfaces have changed in the private
filesystem CLI.

- The directory-selection option for `find` has been renamed.
- The short line-count option for `wc` has been retired.
- A new optimized copy-and-rename operation is available.

Use current command help to determine exact replacement syntax and validate
behavior before updating persistent command recipes.

D2 evidence is intentionally withheld for C3.1.
