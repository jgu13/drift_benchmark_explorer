A5.1 Placement-Codebook Drift Execution Plan

Objective

Build an executable ALFWorld-pattern placement-codebook drift benchmark. Navigation is fixed across regimes; the task is to update accepted placement rules, handle one newly available room, and preserve version-scoped memory during recurrence.

Package Layout

Family root:

alfworld/data/A5.1/

Semantic package:

alfworld/data/A5.1/placement_codebook/

The package contains `placement_inventory.json`, local regime files, `siblings.json`, `possible_answer_r_minus.json`, `possible_answer_r_plus.json`, D2/D3 evidence, compiler, simulator, construction report, and local validators.

Drift Definition

The pilot has 16 object-class placement obligations. Exactly four classes are remapped, meeting the 25% changed-mass requirement:

mug:   kitchen_cabinet -> pantry_cupboard
plate: kitchen_cabinet -> pantry_cupboard
bowl:  kitchen_cabinet -> pantry_cupboard
glass: kitchen_cabinet -> pantry_cupboard

The r+ regime introduces the new room `pantry`. All navigation costs and edges are invariant across regimes for shared rooms, so this family tests placement correctness rather than search efficiency.

Evidence Allocation

D1 = 0%
D2 = 50%
D3 = 50%

D2 covers common remapped classes `mug` and `plate`, each with exactly one success trajectory and one failure trajectory. D3 covers rare remapped classes `bowl` and `glass`, plus confirmation that `pantry` is a valid new room.

`skill_r_minus.md` stores the stale table. `skill_r_plus_oracle.md` stores the hidden r+ table and must remain outside `evidence/`.

Sibling Construction

Build exactly 19 siblings:

8 affected
4 unchanged-retention
4 boundary/open-set
3 matched-null

Use normalized IDs:

A5.1_aff_001 ... A5.1_aff_008
A5.1_ret_001 ... A5.1_ret_004
A5.1_bnd_001 ... A5.1_bnd_004
A5.1_null_001 ... A5.1_null_003

Affected siblings cover D2-covered remapped classes, D3-covered remapped classes, compound take+navigate+put variants, different starting rooms, already-held starts, and return-to-r+ after an r- recurrence block. Retention, boundary, and matched-null siblings exercise unchanged classes, unknown-class abstention, new-room boundary behavior, plausible-but-rejected placements, already-correct placements, paraphrases, and irrelevant state changes.

Compilation

python alfworld/data/A5.1/placement_codebook/compile_a5_1.py --write

Validation

bash alfworld/data/A5.1/placement_codebook/validation/check_a5_1_architecture.sh

The bash validator checks layout, JSON syntax, 16 obligations, exactly four remapped classes, new-room expansion, invariant navigation, 19 siblings with 8/4/4/3 slices, D2 success/failure pairing, D3 probe schema, recurrence annotations, compiled answer coverage, replay, evidence disjointness, and oracle non-leakage.

Limitations

This is a deterministic pilot. Empirical metrics are unmeasured and remain `null`. Primary grading is semantic accepted-placement state; exact trajectory match is diagnostic.
